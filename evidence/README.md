# Evidence

This directory stores proof that design, implementation, review, and release gates were performed.

## Directories

| Directory | Purpose |
|---|---|
| `reviews/` | Reviewer verdicts and findings. |
| `test-runs/` | Functional and security test evidence. |
| `threat-model-updates/` | Threat model update notes. |
| `dependency-reviews/` | Dependency approval/rejection evidence. |
| `release-gates/` | Release readiness evidence. |

## Rule

No feature is complete without evidence.

No release is allowed without release-gate evidence.
